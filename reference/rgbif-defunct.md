# Defunct functions in rgbif

- [`density_spplist()`](https://docs.ropensci.org/rgbif/reference/density_spplist.md):
  service no longer provided

- [`densitylist()`](https://docs.ropensci.org/rgbif/reference/densitylist.md):
  service no longer provided

- [`gbifdata()`](https://docs.ropensci.org/rgbif/reference/gbifdata.md):
  service no longer provided

- [`gbifmap_dens()`](https://docs.ropensci.org/rgbif/reference/gbifmap_dens.md):
  service no longer provided

- [`gbifmap_list()`](https://docs.ropensci.org/rgbif/reference/gbifmap_list.md):
  service no longer provided

- [`occurrencedensity()`](https://docs.ropensci.org/rgbif/reference/occurrencedensity.md):
  service no longer provided

- [`providers()`](https://docs.ropensci.org/rgbif/reference/providers.md):
  service no longer provided

- [`resources()`](https://docs.ropensci.org/rgbif/reference/resources.md):
  service no longer provided

- [`taxoncount()`](https://docs.ropensci.org/rgbif/reference/taxoncount.md):
  service no longer provided

- [`taxonget()`](https://docs.ropensci.org/rgbif/reference/taxonget.md):
  service no longer provided

- [`taxonsearch()`](https://docs.ropensci.org/rgbif/reference/taxonsearch.md):
  service no longer provided

- [`stylegeojson()`](https://docs.ropensci.org/rgbif/reference/stylegeojson.md):
  moving this functionality to spocc package, will be removed soon

- [`togeojson()`](https://docs.ropensci.org/rgbif/reference/togeojson.md):
  moving this functionality to spocc package, will be removed soon

- [`gist()`](https://docs.ropensci.org/rgbif/reference/gist.md): moving
  this functionality to spocc package, will be removed soon

- [`occ_spellcheck()`](https://docs.ropensci.org/rgbif/reference/occ_spellcheck-defunct.md):
  GBIF has removed the `spellCheck` parameter from their API

## Details

The above functions have been removed. See
<https://github.com/ropensci/rgbif> and poke around the code if you want
to find the old functions in previous versions of the package
